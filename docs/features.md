# ShareO 最终功能边界

> 更新时间：2026-07-22

## 核心社区

- 注册、登录、退出、资料和管理员封禁。
- 图文帖子创建、编辑、软删除、审核和 Feed。
- 图片上传、缩略图和 MinIO 代理。
- MySQL FULLTEXT 搜索及 LIKE 降级。

## 社交互动

- 帖子点赞与用户点赞列表。
- 用户关注、粉丝和关注列表。
- 评论、回复和作者删除。
- 点赞、关注、评论、审核通知及未读计数。

## 私聊

- 一对一会话、历史分页、已读游标、未读计数和 WebSocket 下发。
- 固定 `shareo_bot` 私聊；普通用户私聊不触发 AI。

## AI

- approved 图片的 Chinese-CLIP 语义搜索。
- approved 正文的 BGE 文本索引。
- 私聊 Bot 的受限 RAG 回答和帖子引用。

## 删除范围

收藏、转帖、话题、群聊、Agent、工具调用和独立 Bot 页面全部删除。
