# ShareO v2 路线图

> 更新时间: 2026-07-21 | 目标: 成熟、可复现、可量化评测、可稳定演示 | 答辩目标: 2027 春季

项目采用两条状态线：后端能力线可继续推进，发布验收线在后端质量门禁后集中完成。

| 阶段 | 时间估算 | 交付物 | 状态/依赖 |
|------|----------|--------|-----------|
| 可信基线与文档收口 | 1–2 天 | 阶段文档、混合运行命令、统一证据 | 进行中 |
| Phase 2 真实闭环 | 3–5 天 | 模型预热、Qdrant schema、隔离 E2E | 当前主线 |
| Phase 2 可靠性与评测 | 5–8 天 | 对账、故障注入、40 条评测集、性能报告 | 依赖真实闭环 |
| Phase 1/2 发布验收 | 3–5 天 | 搜索页面、双浏览器、部署 origin | 依赖 Phase 2 评测 |
| Phase 3 Bot + RAG | 4–6 周 | 文本索引、引用回答、质量/成本报告 | 依赖 Phase 2 完成 |
| Phase 4 Agent | 2–3 周 | 工具调用、多步任务实验 | 扩展目标，依赖 Phase 3 |
| 论文与答辩 | 2027-03 起 | 系统设计、实验、演示与论文 | Phase 0–3 为核心范围 |

## 毕设完成边界

核心完成范围为 Phase 0–3 及可复现实验。Agent 可在时间不足时降为论文展望，但评测集、实验记录、引用正确性与故障降级不可删减。

## 降级顺序

1. Phase 4 Agent 降为展望。
2. Phase 3 去除 rerank 等增强，保留检索、引用和降级。
3. Phase 2 页面保持最小双模式，不增加复杂交互。
4. 评测、真实依赖和数据一致性门禁不降级。
