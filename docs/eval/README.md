# 评测规范

> 更新时间: 2026-07-19 | 状态: 生效

毕设答辩需要**量化实验**。本目录是所有评测集与实验记录的家，规则：实验当天记录，配置写全，结果可复现。

## 1. 搜图评测（Phase 2 起）

- **评测集**: `image_search_v1.jsonl`，每行 `{"query": "夕阳下的海边", "category": "scene", "relevant_post_ids": [...]}`。
  - v1 已建立 40 条查询，覆盖物体、场景、颜色、风格、构图、人像、运动、抽象和无匹配。
  - 当前数据库清空后查询处于待标注状态；E2E 造数后人工浏览全库填写相关帖子 ID。评测器会拒绝空标签，避免生成虚假报告。
  - 标注完成后冻结 v1；改动标签或查询必须升版并记录原因。
- **指标**: Recall@5、Recall@10、MRR、人工标注相关结果占比、重复帖子率和 P50/P95 延迟。
- **基线**: 现有 MySQL FULLTEXT 关键词搜索作为对照组（语义 vs 关键词，论文核心对比）。
- **运行**: `make eval-image-search`，输出语义与 FULLTEXT 的 Recall@5/10、MRR、人工标注相关结果占比、重复帖子数和 P50/P95。

## 2. RAG 评测（Phase 3 起）

- **评测集**: `rag_qa_v1.jsonl`，每行 `{"question": ..., "expected_source_post_ids": [...], "reference_answer": ...}`，30 条起。
- **指标**:
  - 检索质量：引用命中率（回答引用的帖子 ∩ 标注来源）
  - 回答质量：人工 1~5 分（正确性/相关性/是否幻觉），双人或隔日两次打分取均值
- **对照实验**: 云 LLM (DeepSeek) vs 本地 Qwen2.5-7B (4060/Ollama)，同一评测集比质量/延迟/成本。

## 3. 性能实验

- Embedding 吞吐：M1 Pro (CPU/MPS) vs 4060 (CUDA)，图/秒与批大小关系。
- 搜索延迟：P50/P95（编码 + 检索 + 补全全链路）。
