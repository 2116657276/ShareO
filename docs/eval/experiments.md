## Agent 复评说明

Agent 使用冻结的 36 条任务和现有 `agent-v1`/`agent-trace-v1` 协议。测试 Provider 的结果只证明工具协议、预算、引用过滤和失败语义；真实 Provider 结果受模型、运行时和工作区状态影响，必须记录为单独实验。

历史轮次中的多 tool call 消息闭合、失败轨迹保留、Provider 重试和源码指纹问题已通过工程测试修复。`0.6944`、`0.7778`、`0.8889` 和 `0.9167` 不改变正式门禁，正式门禁仍为必需工具选择率 `≥0.85`。

人工反馈显示回答总体准确，但部分回答参数较多、语言不够自然，“是什么”类问题相对简略。这些属于后续表达风格实验候选，不得替代机器指标，也不在当前发布收口范围内。

## 记录规则

每轮实验追加记录数据集版本与 SHA、代码提交与 dirty 状态、Prompt/工具协议版本、模型与 revision、设备、检索参数、P50/P95、超时率和失败类别。报告不得包含 API Key、Token、Cookie、Authorization header、个人照片、模型权重、缓存路径或完整私聊历史。
