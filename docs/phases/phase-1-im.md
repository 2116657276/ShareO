# Phase 1 — IM 后端与发布验收

> 更新时间: 2026-07-21 | 状态: 后端候选，发布验收待后

## 目标与当前基线

提供事务一致的私聊和邀请制群组。后端、终端和真实 MySQL/Redis 证据已完成，主要实现提交为 `57b9615`。

## 工作包

- DM/建群/发消息/解散事务，成员上限与并发保护。
- 准确未读、单调 MarkRead、before/after 分页和断线补偿。
- JWT+Redis WS 登录校验、多连接吊销、在线 TTL。
- 群主邀请/解散、普通成员退出，错误映射与数据库脱敏。
- 发布验收阶段集中完成双浏览器、断网和部署 Origin。

## 接口与数据流

REST 负责写消息，WebSocket 只下行。客户端按消息 ID 去重，重连后使用 `after_id` 补齐。

## 失败模式

WS 中断不阻塞 REST 写入；登录缓存失效、改密、登出或封禁会断开所有连接；较旧读标记不倒退。

## 测试矩阵

- Hub 多连接、慢连接、吊销和 Redis presence。
- curl 覆盖邀请、退出、解散、恢复、限制和错误映射。
- 发布阶段补双浏览器实时、离线、在线状态和 trusted origin。
