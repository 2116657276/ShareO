# Phase 2 — 一对一私聊

> 状态：已完成

## 目标

提供可靠的一对一文本私聊，并为固定 Bot 用户复用同一消息和页面能力。

## 当前基线

DM 幂等创建、消息事务、准确未读、历史分页、`after_id` 恢复、WebSocket 下行、在线状态和会话吊销已经实现。

## 范围与非目标

只支持两人会话和文本消息；不支持群聊、邀请、踢人、撤回、编辑、图片消息、音视频或端到端加密。

## 依赖

依赖 Phase 1 用户体系，以及 MySQL、Redis 登录缓存和 WebSocket Hub。

## 工作包

- `dm_key=min(uid):max(uid)` 幂等创建两人会话。
- REST 事务写消息，WebSocket 只负责下行。
- `before_id` 历史分页与 `after_id` 断线补偿。
- 准确未读、单调读游标、在线状态和慢连接清理。
- 登出、改密和封禁后主动断开旧连接。

## 接口与数据流

消息先写入 MySQL并更新会话时间和发送者读标记，再由 Hub 推送。客户端按全局消息 ID 合并 REST 响应与 WebSocket 回推。

## 数据一致性

会话、成员和消息使用外键级联；会话只允许两个不同用户；读标记只能推进到本会话真实消息且不能倒退。

## 安全边界

每个会话接口验证成员身份；WebSocket 握手复用 JWT 与 Redis 登录缓存；Origin 只允许同源或精确可信来源。

## 失败模式

WebSocket 失败不影响 REST 落库；重连后通过 `after_id` 补齐；Redis 在线状态失效不影响消息真相。

## 测试矩阵

并发 EnsureDM、事务回滚、越权、分页冲突、未读与读游标、多连接、慢连接、会话吊销和断线补偿。

## 退出标准

并发创建只产生一个 DM；消息不丢不重；越权被拒绝；未读准确；普通用户私聊永不触发 Bot。
