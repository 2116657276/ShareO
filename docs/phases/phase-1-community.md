# Phase 1 — 社区核心

> 状态：已完成

## 目标

提供完整但克制的图文社区主链路，为审核、检索和 RAG 提供可信内容来源。

## 当前基线

认证、资料、图文发布、上传、Feed、全文搜索、审核、点赞、关注、评论和通知已经保留并通过裁剪后回归。

## 范围与非目标

只保留点赞、关注和评论三类社交互动；不恢复收藏、转帖或话题聚合。

## 依赖

依赖 Phase 0 的 MySQL、Redis、MinIO、统一认证和 12 表 schema。

## 工作包

- 注册、登录、退出、资料和密码修改。
- 帖子创建、编辑、软删除、审核、Feed 与 FULLTEXT/LIKE 搜索。
- 图片魔数校验、缩略图生成、MinIO 存储与 Go 代理。
- 点赞、关注、评论及通知、计数和权限校验。

## 接口与数据流

写操作经 Gin Handler → Service 事务 → Repository；帖子只有 `approved AND is_deleted=0` 才进入公共 Feed、互动目标和 AI 索引。

## 数据一致性

帖子与图片级联；互动记录使用唯一约束；点赞和评论计数与明细在同一事务内更新；审核状态变化发布索引事件。

## 安全边界

登录写操作使用完整 JWT/Redis 登录态校验和跨源保护；上传同时检查 MIME、魔数、尺寸与大小；数据库原文错误不返回客户端。

## 失败模式

Redis 缓存失败时回源 MySQL；AI 事件发布失败不回滚已成功的社区事务，由回填和对账修复。

## 测试矩阵

认证、权限、上传魔数、帖子可见性、互动事务、通知、审核、全文搜索降级和管理员边界。

## 退出标准

不可见帖子不能被公共读取或互动；计数与明细一致；上传和审核链路可复现；裁剪功能路由不存在。
