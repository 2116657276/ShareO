# Phase 4 — Agent 扩展目标

> 更新时间: 2026-07-21 | 状态: 扩展目标，依赖 Phase 3

## 目标与当前基线

让 Bot 在严格工具白名单内完成可审计的多步任务。该阶段不属于核心毕业项目完成范围。

## 工作包

- 只读工具：`search_images`、`search_posts`、`get_post`、`summarize_thread`。
- 唯一写能力 `draft_post` 只生成草稿和确认链接，不直接发布。
- 最多 5 轮、单任务 60 秒、参数校验、工具白名单和结构化轨迹。
- 15 个多步任务评估完成率、平均步数、恢复和工具选择。

## 接口与数据流

Agent 复用 Phase 2/3 已稳定的内部接口，通过 function calling 选择工具；所有写入仍由 Go 业务服务完成。

## 失败模式

越权工具、非法参数、循环、超时和 provider 故障均停止任务并返回安全兜底；不自动执行不可逆操作。

## 测试矩阵

工具 schema、权限、轮次/时间限制、循环检测、失败恢复、确认制写操作和完整轨迹。

## 退出标准

15 个任务报告、工具安全测试和演示证据齐全；若时间不足则降为论文展望。

## 证据矩阵

尚无实现证据。

## 暂缓项

Phase 3 达标前不编写 Agent 运行时代码。
