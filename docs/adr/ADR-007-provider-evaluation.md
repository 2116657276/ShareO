# ADR-007：真实 Provider 与质量评测策略

- 日期：2026-07-23
- 状态：已接受

## 背景

项目需要真实LLM证据，但把DeepSeek、Ollama、4060和多provider成本对比全部设为门禁会引入不必要的网络、硬件和评测负担。

## 决定

- OpenAI-compatible接口保持通用，DeepSeek是唯一强制真实验收provider。
- mock provider只用于确定性E2E，不计入真实质量证据。
- Ollama和4060是可选实验，不阻塞项目完成。
- 发布评测固定为40条搜图和30条RAG问答。
- DeepSeek总延迟只记录P50/P95与超时率，不设硬阈值；本地检索保留性能门禁。

## 质量门禁

- 搜图 Recall@5 ≥ 0.70、MRR ≥ 0.55。
- RAG来源命中率 ≥ 0.80、引用可访问率100%、虚假引用0。
- 人工回答相关性平均 ≥ 4.0/5。
- 图片搜索预热后MPS P95 ≤ 2秒、CPU P95 ≤ 4秒；RAG本地检索P95 ≤ 2秒。

## 后果

评测报告必须记录数据集、模型、Prompt、日期、设备和网络环境。API Key不得进入仓库、日志、截图或报告。供应商网络波动不会单独阻塞发布，但超时率必须透明记录。
