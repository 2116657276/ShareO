# ADR-009：私人收藏与消息入口分流

- 日期：2026-07-29
- 状态：已接受

## 背景

收藏曾因早期范围压缩被文档误记为最终移除。产品确认收藏仍属于目标能力，但它与公开点赞语义不同；同时社区通知和私聊未读需要在导航中分流。

## 决定

- 恢复私人收藏：仅收藏者本人可查看，不通知作者、不公开数量、不参与热门排序。
- 点赞保持公开，并继续产生作者通知。
- 收藏使用独立关系表和登录态接口，不提供按任意用户查询收藏的接口。
- 社区通知只展示关注、点赞和评论；只有未读评论点亮“我的”红点。
- 私聊未读只显示在“私聊”导航，私聊列表只展示已经产生消息的会话。
- 搜索页“问问小O”复用既有 `shareo_bot` 私聊和 `ai_mode=agent`，不新增公开 Agent API。

## 后果

- ADR-006 中排除收藏的决定被本 ADR 部分取代；转帖、话题和群聊仍不在范围。
- 已有数据库通过增量迁移增加 `favorites`，新环境基线同时包含该表。
- 收藏关系在帖子暂时不可见时保留，但列表只返回 approved 且未删除帖子。
