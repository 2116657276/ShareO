# Phase 8 前端人工验收清单

> 状态：待用户执行。本文只记录浏览器人工验收步骤；本机模板、路由、API 和自动化检查已完成，浏览器与 Docker/Compose 尚未执行。

## 执行前

1. 使用本机服务启动方式运行 Go、AI、MySQL、Redis、MinIO 和 Qdrant；确认 `/readyz/agent`、`/readyz/rag`、`/readyz/image-search` 均为 ready。
2. 使用普通账号验证社区和私聊；使用独立管理员账号验证审核和管理页面。不要在截图、录屏或日志中展示密码、Token、Cookie、Authorization header、API Key、个人照片原图或完整私聊历史。
3. 记录浏览器、系统、日期和每个场景的结果。失败时记录页面 URL、脱敏错误提示、复现步骤和是否恢复，不直接修改数据库或评测数据。

## 页面与功能

| 场景 | 操作 | 通过标准 |
|---|---|---|
| 登录/注册 | 注册临时普通账号，退出后重新登录；切换普通/管理员登录入口 | 表单提示清晰，登录后按角色进入正确页面，退出后不能访问受保护页面 |
| Feed/全文搜索 | 打开 `/home`，切换最新/热门，执行有结果和无结果搜索，加载更多 | 导航、卡片、图片失败占位、加载/空结果/错误状态正常；帖子链接可打开 |
| 发布/编辑 | 上传一张或多张图片，拖拽和键盘触发上传，填写描述并发布；打开帖子编辑 | 上传进度和失败提示正常；发布后进入审核状态；编辑后展示最新内容并回到审核流程 |
| 管理审核 | 管理员打开仪表盘、审核页、用户页和日志页；通过或驳回临时帖子 | 普通用户不能进入管理页；管理员操作成功或显示受控错误；不泄露内部日志字段 |
| 帖子/互动 | 打开帖子详情，切换多图，点赞、评论、进入作者主页并发起私信 | 图片轮播、键盘焦点、评论加载/空/失败状态正常；互动结果不重复 |
| 用户/通知 | 打开个人主页、作品/点赞切换、设置、通知，执行全部已读 | 页面状态完整，权限和错误提示清晰，链接跳转正确 |
| 语义搜图 | 打开 `/search/images`，输入 1–200 字符中文描述；分别验证有结果、无结果和服务不可用 | 搜索按钮状态、结果卡片、作者/描述、帖子跳转、空结果和 503 提示正常；不显示内部地址或参数 |
| 普通私聊 | 搜索普通用户、创建会话、发送消息、刷新页面、分页加载和断线恢复 | 消息先落库，重复消息不重复；WebSocket 实时到达；断线后自动重连或显示受控提示 |
| RAG Bot | 私聊 `shareo_bot`，关闭深度分析，询问有答案和无答案问题 | 返回受控回答和可访问引用；无答案或 AI 不可用时不伪造引用；普通私聊不受影响 |
| Agent | 打开同一 Bot 会话的“深度分析”，提出需要多来源比较的问题，刷新页面 | 显示完成后的脱敏步骤卡片、引用和状态；引用只能打开 approved 帖子；不展示 Prompt、原始工具参数或思维链 |
| 响应式/错误页 | 缩放到手机宽度，访问不存在地址、无权限页面和服务不可用状态 | 导航可用，表单不溢出，按钮和焦点可操作，404/401/403/429/503 提示清楚 |

## Agent 抽查

从最新机器报告中抽查 10 条答案，逐条核对问题理解、答案正确性、完整性、来源是否恰当、引用是否可打开、步骤是否合理和语言自然度。人工抽查只作为最终体验验收，不修改机器报告中的工具命中或引用指标；若发现问题，记录任务 ID 和页面表现，返回前端或后端阶段修复。
