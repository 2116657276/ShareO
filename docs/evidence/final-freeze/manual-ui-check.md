- 2026-08-11 的当前 PostgreSQL/pgvector 服务、API 回归和图片 seed 重验见 [`docs/REVIEW.md`](../../REVIEW.md)，不把本条历史记录升级为迁移后的浏览器 E2E 证据。
- 本机已重复执行可检查迁移 `003_comment_likes.sql` 和 `004_bot_task_outbox.sql`。
- 通过注册页创建普通本地 smoke 账号；未修改管理员或 Bot 账号。
- 使用帖子 `#78`《这只小狗笑得太开心了》验证评论互动；使用另一普通测试账号写入一条未读私聊。

## 验收结果

| 链路 | 操作与结果 |
|---|---|
| 登录与 Feed | 注册并登录 smoke 账号后进入 Feed；主页、搜索、私聊和个人中心五项导航均可见。 |
| 评论互动 | 在 `#78` 发布 smoke 评论并点亮“点赞评论”；按钮状态切换为“取消评论点赞”。 |
| 私聊未读 | 另一普通用户写入一条消息后，导航和会话列表都显示 `1 条未读私聊`；打开会话后徽标清除。 |
| 问问小 O | 在 Agent 会话发送“帮我找一条关于狗狗的作品，并说明作者”，收到 1 个可点击引用卡片和 Agent 步骤卡片。 |
| 主题 | 在设置中切换黑白主题，`html[data-theme]` 为 `mono` 且按钮 `aria-pressed=true`，随后恢复琥珀主题。 |
| 空状态 | 私聊空列表和帖子无内容状态均能显示稳定提示，不出现模板错误。 |

本次 smoke 还验证了未读接口字段与导航徽标一致；对应契约为 `GET /api/v1/conversations/unread-count` 的 `data.total`。

## 自动化浏览器边界

同日使用 Codex 应用内浏览器针对本机同一服务尝试固定 smoke 流程；宿主机 `curl` readiness 已通过，但浏览器运行环境对 `127.0.0.1`/`localhost` 返回连接拒绝，切换宿主映射地址后又发生连接超时。因此本次不能记录“浏览器自动化通过”，仅保留上面的人工浏览器 smoke 摘要作为补充证据。该失败归因于浏览器环境隔离，不代表页面断言失败。

## 未覆盖范围

WebSocket 实时下行、移动端真实视口、完整搜图交互和人工复核质量评分不在本条 smoke 中；它们分别由工程测试、搜图评测、浏览器环境人工复核或 [AI judge 人工复核交接包](ai-judge-human-handoff.json)覆盖。不得把本条人工记录表述为完整浏览器 E2E。
